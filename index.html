Komplex

An 800 × 600 Mandelbrot explorer in C++ and SDL. Eight POSIX threads render fixed horizontal bands, with up to 200 escape-time iterations per pixel and interactive pan and zoom.

How I approach the work

  • A free plan firstI turn your requirements into a clear outline, choose a sensible approach, and agree the scope with you at no charge.
  • Then I write codeI start programming only when we both know what the result should do and what belongs in the first version.
  • Efficient for youI do not pick whatever is easiest for me. I look for the solution that will run and work best for the person using it.

The code should make your work easier, not mine.

I explain technical decisions in plain language, show progress early, and say openly when a simpler solution makes more sense.
