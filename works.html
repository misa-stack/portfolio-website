C++ · SDL · My own engine

Chess

I write the engine behind the moves: legal move generation, position evaluation, and search. You can play through the SDL interface or run the same engine from the command line over UCI.

Inside Chess

The rules come before the clever moves.

Open full screenshot ↗

Before choosing a move, the engine has to know which moves are legal. It handles check, castling, en passant, promotion, repetition, and the fifty-move draw. The SDL interface adds undo, reset, and fullscreen play. The screenshot shows the current app after a scripted opening.

  1. Keep a move ready as the search goes deeper.

    Iterative deepening finishes one depth before starting the next. That leaves a completed result available if the search has to stop.

  2. Try promising moves first.

    Move ordering helps alpha-beta pruning skip branches of the search. A transposition table reuses results when different move sequences reach the same position.

  3. Follow the exchanges before judging the position.

    Quiescence search follows tactical exchanges beyond the main search depth. The evaluation weighs material, piece placement, pawn structure, and king safety.

C++ · Qt 6 · Interactive mathematics

Komplex

A C++ and Qt 6 app for exploring Mandelbrot, Julia, Burning Ship, and Tricorn fractals. You can change the parameters, zoom into the result, and read the maths behind it alongside the image.

Inside Komplex

Zoom while the image catches up.

Open full screenshot ↗

Each fractal remembers its view while you switch between them. Drag to pan, zoom around the pointer, and raise the iteration limit for more detail. CPU workers render tiles in the background. Quick previews respond to movement first; the full image follows once you stop.

See what happens when you change c.

Open full screenshot ↗

In the Julia view, each pixel starts at a different complex number and repeats z² + c. You can adjust the real and imaginary parts of c, or start with one of three presets. The image makes the effect visible; the lesson explains the calculation.

Read the maths, then try the view.

Open full screenshot ↗

The learning panel covers the basics, mathematics, and history of each fractal in Czech and English. A lesson can load a view for you to explore, so the explanation stays next to its example. All lessons work offline.

C++ · SDL · Artillery game

Iron Duel

A local turn-based artillery game in C++ and SDL. Explosions carve into the terrain, and unsupported ground falls. Where a shot lands changes the ground for the next turn.

Watch a local match

The video could not load. You can download it using the link below.

The ground is part of the game.

The terrain is a destructible pixel grid, generated as hills, mountains, or desert. Five projectile types change how each shot behaves. The game also tracks tank health, takes care of turns, and lets players buy equipment between rounds.
